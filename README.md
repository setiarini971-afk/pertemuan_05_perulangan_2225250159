Tujuan
Mempelajari penggunaan perulangan "for" dan "while" dalam Python untuk menyelesaikan masalah yang membutuhkan proses berulang, memahami perubahan nilai variabel, serta menentukan kondisi berhenti pada perulangan.

Daftar Program
1. "01_tabel_perkalian.py" — Menampilkan tabel perkalian dari bilangan yang dimasukkan.
2. "02_jumlah_bilangan.py" — Menghitung jumlah bilangan dari 1 sampai n.
3. "03_validasi_input.py" — Memvalidasi nilai ujian agar berada pada rentang 0–100.
4. "04_hitung_genap.py" — Menghitung banyak bilangan genap dari 1 sampai n.
5. "kuis2_deret_aritmetika.py" — Menampilkan suku dan menghitung jumlah deret aritmetika.

Cara Menjalankan
Jalankan program melalui terminal VS Code dengan perintah:

python3 latihan/01_tabel_perkalian.py

Untuk menjalankan kuis:
python3 kuis/kuis2_deret_aritmetika.py
Jika menggunakan Windows, perintah "python" dapat digunakan sebagai pengganti "python3".

Algoritma
Program menggunakan perulangan "for" untuk mengulang proses dengan jumlah pengulangan yang sudah diketahui. Perulangan "while" digunakan ketika proses bergantung pada suatu kondisi. Variabel penghitung atau penjumlahan diperbarui selama perulangan agar proses berjalan dan berhenti sesuai kondisi.

Hasil Pengujian
- Tabel perkalian: diuji dengan input 4 dan -3.
- Jumlah bilangan: diuji dengan input 1, 5, dan 10.
- Validasi input: diuji dengan input 120, -5, dan 75.
- Hitung genap: diuji dengan input 1, 2, 5, dan 10.
- Deret aritmetika: diuji dengan beberapa nilai suku pertama, beda, dan banyak suku.

Refleksi
Melalui latihan ini, saya memahami bahwa perulangan "for" sesuai digunakan ketika jumlah pengulangan sudah diketahui, sedangkan "while" digunakan ketika pengulangan bergantung pada kondisi. Saya juga belajar bahwa nilai awal, kondisi, dan pembaruan variabel perlu diperhatikan agar perulangan berhenti dengan benar dan tidak terjadi kesalahan.
